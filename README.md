# Начало в автотесты

Отдельный учебный проект: Java 21, Maven, JUnit 5 и Selenide.
Он не зависит от рабочего проекта autotest_framework.

## Справочник для начинающего

[Словарь Java для автотестов](СЛОВАРЬ_ДЛЯ_АВТОТЕСТОВ_JAVA.md) — ключевые слова Java 21,
символы, типы данных, аннотации JUnit, команды Selenide и селекторы.
Формат: «обозначение → значение → пример». Начинай с разделов 1, 2 и 11.

## Открытие в IntelliJ IDEA

1. Выбери **File → Open** и открой `pom.xml` из этой папки как проект.
2. Выбери **New Window**, чтобы не закрывать рабочий проект.
3. Дождись загрузки Maven-зависимостей. Если IDEA предложит импорт Maven-проекта, согласись.
4. В **File → Project Structure → Project SDK** выбери JDK 21.
5. Открой `src/test/java/SearchTests.java`.
6. Нажми зелёный треугольник рядом с `successfulSearchTest` и выбери **Run**.

Папку `untitled` открывать не нужно: это не Maven-проект. Она оставлена без изменений.

## Запуск из терминала

Открой терминал в корне проекта — там, где расположен `pom.xml`.

Проверить компиляцию, не запуская браузер:

```powershell
mvn -DskipTests test
```

Запустить браузерный тест (нужен установленный Chrome и доступ в интернет):

```powershell
mvn test
```

Selenide открывает Chrome, ищет `qa.guru` на GitHub и проверяет наличие
`QA.GURU` в результатах. Метод `main` не нужен: тест запускает JUnit.
Импорты находятся перед единственным классом `SearchTests`.

## Логи в консоли

SLF4J Simple выводит сообщения уровня INFO и выше в стандартный вывод консоли.
Настройки находятся в `src/test/resources/simplelogger.properties`.
Формат: время, поток, уровень, имя логгера и сообщение.
Для более подробных логов замени `defaultLogLevel=info` на `defaultLogLevel=debug`.
Эта настройка не включает пошаговый отчёт о каждом действии Selenide.

Проверить логгер без открытия браузера:

```powershell
mvn -Dtest=LoggingConfigurationTest test
```

После изменения `pom.xml` нажми **Reload All Maven Projects** в IDEA.
Предупреждения Selenium о CDP не скрываются: они относятся к совместимости браузера,
а не к отсутствию SLF4J-логгера.

## Если тест не прошёл

- Красные импорты: дождись Maven-синхронизации или нажми **Reload All Maven Projects**.
- `Element not found`: проверь страницу и селекторы — GitHub может изменить разметку.
- `Unable to find an exact match for CDP version`: это предупреждение о соответствии
  версии Selenium протоколу браузера. Само по себе оно не означает падение теста;
  проверяй итоговый статус JUnit и ошибки ниже в журнале.
- Загрузка зависимостей или драйвера требует доступа в интернет.

Результаты сборки `target/`, отчёты Selenide `build/` и настройки IDEA исключены из Git.
## Практика Git

Учебный репозиторий: https://github.com/RaGnAr666999/java-autotests-learning

Для задания используются ветки `main` и `homework/conflict`. В файле
`git-practice.txt` одна строка намеренно изменена по-разному в этих ветках.
Это создаёт конфликт при попытке слияния. Для сдачи задания Pull request
из `homework/conflict` в `main` нужно оставить открытым и не разрешать конфликт.
Java-тесты в обеих ветках одинаковы; конфликт не является падением теста.
