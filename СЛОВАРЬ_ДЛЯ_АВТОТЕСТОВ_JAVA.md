## 1. С чего начать

Сначала изучи `import`, `class`, `void`, `String`, `new`, `=`, `()`, `{}`, `;`, затем `@Test`, `open`, `$`, `setValue`, `click`, `shouldHave`, `shouldBe`.

**Не нужно учить весь справочник перед первым тестом.** Разделы про модули, потоки и наследование пригодятся позже.

| Обозначение | Что это | Что важно понять |
|---|---|---|
| Java | Язык программирования | Описывает действия и проверки |
| Ключевое слово | Слово со специальным значением в языке | Например, `class` нельзя использовать как имя переменной |
| Класс | Объявленный тип; объединяет данные и методы | Класс тестов содержит методы тестов |
| Объект | Экземпляр класса | `new ArrayList<String>()` создаёт объект списка |
| Метод | Именованное действие | `click()` нажимает на элемент |
| Переменная | Имя, связанное со значением | `String name = "Анна";` |
| Параметр | Переменная в объявлении метода | В `void greet(String name)` параметр — `name` |
| Аргумент | Конкретное значение при вызове | В `greet("Анна")` аргумент — `"Анна"` |
| Поле | Переменная, объявленная в классе вне методов | Может хранить данные, используемые несколькими методами |
| Аннотация | Дополнительная информация для инструментов | `@Test` сообщает JUnit, что метод является тестом |
| Библиотека | Готовые классы и методы | JUnit и Selenide — не ключевые слова Java |
| Проверка | Сравнение фактического результата с ожидаемым | Если условие не выполнено, тест должен упасть |

## 2. Файл и структура теста

```text
Начало в автотесты/
├── pom.xml                         ← зависимости и настройки Maven
├── src/
│   └── test/
│       ├── java/                    ← Java-классы тестов
│       │   └── SearchTests.java
│       └── resources/               ← данные и настройки тестов
│           └── simplelogger.properties
└── target/                          ← результат сборки; вручную не редактируем
```

| Обозначение | Значение | Пример / правило |
|---|---|---|
| `.java` | Файл исходного Java-кода | `SearchTests.java` |
| `.class` | Скомпилированный код | Создаётся автоматически в `target/test-classes` |
| `package` | Пакет, к которому относится класс | `package learning;` — первая строка перед импортами |
| `import` | Позволяет использовать тип по короткому имени | `import org.junit.jupiter.api.Test;` |
| `import static` | Позволяет вызывать статический метод или использовать поле без имени класса | `import static com.codeborne.selenide.Selenide.open;` |
| `public class SearchTests` | Объявление доступного извне класса | Имя публичного класса совпадает с именем файла |
| `void successfulSearchTest()` | Объявление метода, который не возвращает значение | В скобках находятся параметры; здесь их нет |
| `@Test` | Аннотация JUnit | Ставится перед методом теста |

Порядок в обычном файле: **package (если есть) → import → класс → методы внутри класса**.
Импорты нельзя помещать внутрь класса. Не вставляй второй `SearchTests` внутрь уже созданного `SearchTests`.

В текущем проекте `SearchTests` находится прямо в `src/test/java`, поэтому строки `package` у него нет.
Если создашь `src/test/java/learning/MyTests.java`, первой строкой будет `package learning;`.

## 3. Все зарезервированные ключевые слова Java 21

### Структура, доступ и объекты

| Ключ | Значение | Пример |
|---|---|---|
| `package` | Объявляет пакет | `package learning;` |
| `import` | Импортирует тип или статический член | `import java.util.List;` |
| `class` | Объявляет класс | `class LoginTests { }` |
| `interface` | Объявляет интерфейс — контракт поведения | `interface Page { void open(); }` |
| `enum` | Объявляет тип с перечисленными константами | `enum Role { USER, ADMIN }` |
| `extends` | Указывает родительский класс; также наследование интерфейсов | `class LoginTests extends BaseTest { }` |
| `implements` | Указывает реализуемые классом интерфейсы | `class LoginPage implements Page { ... }` |
| `public` | Разрешает доступ с учётом доступности типа и модуля | `public class SearchTests { }` |
| `protected` | Доступ внутри пакета и для наследников с дополнительными правилами | `protected String baseUrl;` |
| `private` | Ограничивает доступ рамками охватывающего верхнеуровневого класса и его вложенных типов | `private String name;` |
| `static` | Член принадлежит классу, а не отдельному объекту | `static int count;` |
| `final` | Запрещает повторное присваивание переменной; переопределение метода или наследование класса | `final String name = "Анна";` |
| `abstract` | Класс нельзя создать напрямую; метод не имеет реализации | `abstract class BaseTest { abstract void prepare(); }` |
| `new` | Создаёт объект или массив | `new ArrayList<String>()` |
| `this` | Ссылка на текущий объект; также вызов другого конструктора своего класса | `this.name = name;` |
| `super` | Обращение к родительскому классу; вызов его конструктора | `super.toString()` |
| `instanceof` | Проверяет совместимость объекта с типом | `value instanceof String` |

**Отсутствие модификатора доступа** означает доступ внутри пакета. Слова `default` для такого доступа перед полем или обычным методом не пишут.
`final` у ссылки не делает сам объект неизменяемым: содержимое `final List<String>` может меняться.

### Примитивные типы и отсутствие результата

| Ключ | Значение | Пример |
|---|---|---|
| `boolean` | Логическое значение | `boolean active = true;` |
| `byte` | Целое число от −128 до 127 | `byte attempts = 3;` |
| `short` | Целое число от −32768 до 32767 | `short year = 2026;` |
| `int` | 32-битное целое число | `int age = 25;` |
| `long` | 64-битное целое число | `long count = 3_000_000_000L;` |
| `float` | 32-битное число с плавающей точкой | `float ratio = 1.5F;` |
| `double` | 64-битное число с плавающей точкой | `double ratio = 1.5;` |
| `char` | Одна 16-битная кодовая единица UTF-16 | `char letter = 'А';` |
| `void` | Метод не возвращает значение | `void login() { ... }` |

`char` не всегда вмещает целый видимый символ: например, многие эмодзи представлены парой `char`.
`float` и `double` хранят числа приближённо; для точных денежных расчётов обычно используют `BigDecimal`.

### Условия, циклы и переходы

| Ключ | Значение | Пример |
|---|---|---|
| `if` | Выполнить блок, если условие истинно | `if (age >= 18) { ... }` |
| `else` | Иначе выполнить другой блок | `if (active) { ... } else { ... }` |
| `switch` | Выбор по значению; бывает оператором и выражением | `switch (role) { case "admin" -> ...; default -> ...; }` |
| `case` | Вариант внутри `switch` | `case "admin" -> "Администратор";` |
| `default` | Ветка `switch` по умолчанию; также метод интерфейса с реализацией и значение элемента аннотации | `default void prepare() { }` в интерфейсе |
| `for` | Цикл со счётчиком или перебор элементов | `for (int i = 0; i < 3; i++) { ... }` |
| `while` | Повторять, пока условие истинно | `while (count < 3) { count++; }` |
| `do` | Цикл с проверкой условия после тела | `do { count++; } while (count < 3);` |
| `break` | Прервать цикл или выйти из `switch`-оператора; возможна метка | `if (found) { break; }` |
| `continue` | Перейти к следующему шагу цикла | `if (skip) { continue; }` |
| `return` | Завершить метод; при необходимости вернуть результат | `return name;` или `return;` в `void`-методе |

Пример перебора: `for (String name : names) { ... }` — по очереди взять каждое имя из `names`.
Не используй `if` так, чтобы при отсутствии нужного элемента тест просто пропускал проверку и становился зелёным.

### Ошибки и проверки языка

| Ключ | Значение | Пример |
|---|---|---|
| `try` | Блок, в котором может возникнуть исключение; также управление ресурсами | `try { ... } catch (Exception e) { ... }` |
| `catch` | Обработка подходящего исключения | `catch (IOException e) { ... }` |
| `finally` | Завершающий блок, обычно выполняемый независимо от результата `try` | `finally { closeWebDriver(); }` |
| `throw` | Выбросить конкретное исключение | `throw new IllegalArgumentException("Пустое имя");` |
| `throws` | Объявить возможные исключения метода | `void readFile() throws IOException { ... }` |
| `assert` | Встроенная проверка языка, обычно выключенная без `-ea` | `assert age >= 0;` |

В автотестах используй проверки **JUnit или Selenide**, а не языковой `assert`: они работают без `-ea`.
Не скрывай падения пустым `catch`. `finally` не гарантируется при принудительном завершении процесса.

### Потоки, сериализация и специальные случаи

| Ключ | Значение | Пример |
|---|---|---|
| `synchronized` | Синхронизирует доступ через монитор объекта | `synchronized (lock) { ... }` |
| `volatile` | Обеспечивает правила видимости и упорядочивания чтений/записей поля между потоками | `volatile boolean stopped;` |
| `transient` | Исключает поле из стандартной Java-сериализации объекта | `transient String password;` |
| `native` | Метод реализован вне Java, например в нативной библиотеке | `native void execute();` |
| `strictfp` | Исторически задавал строгие вычисления с плавающей точкой; в Java 21 избыточен | `strictfp class Calculator { }` |
| `const` | Зарезервировано, но не используется | Для константы обычно пишут `static final` |
| `goto` | Зарезервировано, но не используется | Не применяй как имя |
| `_` | Одиночное подчёркивание зарезервировано | В обычном Java 21 нельзя назвать переменную `_`; `user_name` допустимо |

`volatile` не делает составные операции вроде `count++` атомарными.
В справочнике используется Java 21 **без preview-функций** — экспериментальных возможностей, требующих отдельного включения.

## 4. Контекстные ключевые слова

Эти 17 обозначений имеют специальное значение только в определённых местах программы. Для некоторых действуют дополнительные ограничения на имена типов и методов.

| Ключ | Значение | Пример / место применения |
|---|---|---|
| `var` | Компилятор выводит тип локальной переменной из начального значения | `var name = "Анна";` — тип остаётся `String`, не может стать числом |
| `record` | Компактное объявление класса данных | `record User(String name, int age) { }` |
| `sealed` | Ограничивает список непосредственных наследников | `sealed interface Result permits Success, Failure { }` |
| `permits` | Перечисляет разрешённых наследников sealed-типа | `permits Success, Failure` |
| `non-sealed` | Снимает ограничение наследования у наследника sealed-типа | `non-sealed class Success implements Result { }` |
| `yield` | Возвращает значение из блока ветки `switch`-выражения | `case 1 -> { yield "Один"; }` |
| `module` | Объявляет модуль | `module learning.tests { ... }` в `module-info.java` |
| `open` | Объявляет модуль открытым для глубокой рефлексии | `open module learning.tests { ... }` |
| `requires` | Зависимость модуля | `requires java.sql;` |
| `transitive` | Делает зависимость доступной также модулям-потребителям | `requires transitive java.sql;` |
| `exports` | Делает публичные типы пакета доступными другим модулям | `exports learning.api;` |
| `opens` | Открывает пакет для глубокой рефлексии | `opens learning.model;` |
| `to` | Ограничивает `exports` или `opens` указанными модулями | `exports learning.api to client.module;` |
| `uses` | Объявляет использование сервиса | `uses learning.api.Service;` |
| `provides` | Объявляет реализацию сервиса | `provides learning.api.Service with learning.impl.ServiceImpl;` |
| `with` | Отделяет сервис от списка реализаций | Используется с `provides` |
| `when` | Дополнительное условие для шаблона в `case` | `case String s when s.isBlank() -> "Пусто";` |

**Не путай:** `open` в `open module ...` — слово Java, а `open("https://...")` в тесте — метод библиотеки Selenide.
`record` не делает вложенные изменяемые объекты неизменяемыми. `var` нельзя использовать вместо типа обычного поля или результата метода.
Обычный учебный Maven-проект не требует `module-info.java`.

## 5. Значения и типы данных

| Обозначение | Значение | Пример |
|---|---|---|
| `true` | Истина: логический литерал, не ключевое слово | `boolean enabled = true;` |
| `false` | Ложь: логический литерал | `boolean enabled = false;` |
| `null` | Отсутствие ссылки на объект: null-литерал | `String name = null;` |
| `String` | Класс для строк, не ключевое слово | `String email = "test@example.com";` |
| `Integer`, `Long`, `Boolean`, `Double` | Объектные оболочки примитивных типов | `List<Integer> ages = List.of(20, 30);` |
| `Object` | Общий родительский класс для классов | `Object value = "текст";` |
| `String[]` | Массив строк | `String[] names = {"Анна", "Иван"};` |
| `List<String>` | Упорядоченный список строк | `List<String> names = List.of("Анна", "Иван");` |
| `Set<String>` | Набор уникальных строк | `Set<String> roles = Set.of("USER", "ADMIN");` |
| `Map<String, String>` | Соответствие ключей значениям | `Map<String, String> user = Map.of("name", "Анна");` |

Примеры требуют подходящих импортов, например `import java.util.List;`.
Коллекции, созданные через `List.of`, `Set.of`, `Map.of`, нельзя изменять; они не принимают `null`.

```java
String name = "Анна";
// String — тип; name — имя; = — присваивание; "Анна" — значение; ; — конец инструкции.

int age = 25;
boolean adult = age >= 18;
```

Примитив `int` не может быть `null`, а `Integer` может. Вызов метода у `null` обычно приводит к `NullPointerException`.
Локальную переменную нужно инициализировать до чтения. Значения по умолчанию у полей не означают, что так же можно читать неинициализированную локальную переменную.

### Как называть

| Что | Пример | Правило |
|---|---|---|
| Класс | `LoginTests` | Каждое слово с большой буквы |
| Метод / переменная | `successfulLoginTest`, `userName` | Первое слово с маленькой буквы, последующие с большой |
| Константа | `BASE_URL` | Обычно большие буквы с подчёркиванием |
| Пакет | `learning.pages` | Маленькие буквы, без пробелов |

Регистр важен: `String` и `string` — разные имена. Русские имена допустимы в ряде мест языка, но для классов, пакетов и методов обычно выбирают латиницу.

## 6. Символы и операторы

Некоторые примеры ниже — фрагменты, а не самостоятельные программы.

| Обозначение | Значение | Пример |
|---|---|---|
| `;` | Конец инструкции; также разделитель частей обычного `for` | `open("https://example.com");` |
| `{ }` | Тело класса, метода, блока; также инициализатор массива | `void test() { ... }` |
| `( )` | Параметры/аргументы метода, группировка, условия, приведение типа | `click()`, `if (active)`, `(String) value` |
| `[ ]` | Массив и доступ по индексу | `names[0]` |
| `.` | Доступ к члену, разделитель пакетов | `name.length()` |
| `,` | Разделяет аргументы, параметры и элементы | `assertEquals("Анна", actualName)` |
| `"..."` | Строка | `"Привет"` |
| `'...'` | Один `char`, не строка | `'А'` |
| `"""` | Начало/конец многострочного текстового блока | После открывающего разделителя необходим перевод строки |
| `//` | Комментарий до конца строки | `// Открываем страницу` |
| `/* ... */` | Многострочный комментарий | `/* Пояснение */` |
| `/** ... */` | Документирующий комментарий | Используется инструментом Javadoc |
| `@` | Аннотация; в `@interface` — объявление типа аннотации | `@Test`, `@Override` |
| `=` | Присвоить значение | `age = 25` |
| `==` | Равенство примитивных значений или ссылок | `age == 25`; строки по содержимому сравнивай через `equals` |
| `!=` | Неравенство значений или ссылок | `name != null` |
| `>`, `<`, `>=`, `<=` | Сравнение чисел | `age >= 18` |
| `+` | Сложение; соединение строк; унарный плюс | `2 + 3`, `"Имя: " + name` |
| `-` | Вычитание или смена знака | `5 - 2`, `-age` |
| `*` | Умножение; отдельно применяется в импортировании по требованию | `2 * 3`, `import java.util.*;` |
| `/` | Деление | `5 / 2` даёт `2`, а `5.0 / 2` — `2.5` |
| `%` | Остаток от деления | `5 % 2` даёт `1` |
| `++`, `--` | Увеличить/уменьшить на один | `count++`; префиксная и постфиксная формы возвращают разное значение |
| `+=`, `-=`, `*=`, `/=`, `%=` | Операция с присваиванием и неявным приведением к типу левой части | `count += 2` |
| `!` | Логическое НЕ | `!active` |
| `&&` | Логическое И; правое условие вычисляется только при необходимости | `name != null && !name.isBlank()` |
| `\|\|` | Логическое ИЛИ; правое условие вычисляется только при необходимости | `admin \|\| owner` |
| `&`, `\|`, `^` | Побитовые операции с целыми; логические операции с boolean без короткого замыкания | `flags & mask`, `a ^ b` |
| `~` | Побитовое НЕ | `~flags` |
| `<<`, `>>`, `>>>` | Сдвиг битов влево; вправо со знаком; вправо с заполнением нулями | `value >>> 1` |
| `&=`, `\|=`, `^=`, `<<=`, `>>=`, `>>>=` | Побитовая операция или сдвиг с присваиванием | `flags &= mask` |
| `? :` | Выбор одного из двух значений по условию | `age >= 18 ? "Взрослый" : "Ребёнок"` |
| `:` | Также метка, разделитель в переборе `for`, части старого `case` | `for (String name : names)` |
| `->` | Лямбда-выражение или ветка современного `switch` | `names.forEach(name -> System.out.println(name));` |
| `::` | Ссылка на метод или конструктор | `names.forEach(System.out::println);` |
| `<String>` | Параметр типа, а не сравнение | `List<String>` — список строк |
| `<>` | Вывод параметров типа при создании объекта | `new ArrayList<>()` |
| `?` | Неизвестный параметр обобщённого типа | `List<?>`; ограничения: `? extends Number`, `? super Integer` |
| `...` | Переменное количество аргументов | `void check(String... values) { }` |
| `$` | Допустимый символ имени; сам по себе не оператор Java | `$()` — имя метода Selenide |

### Спецсимволы в строках

| Обозначение | Значение | Пример |
|---|---|---|
| `\n` | Перевод строки | `"Первая\nВторая"` |
| `\t` | Табуляция | `"Имя\tАнна"` |
| `\r` | Возврат каретки | Обычно встречается в переводах строк Windows вместе с `\n` |
| `\b` | Возврат на один символ | Экранированная управляющая последовательность |
| `\f` | Перевод страницы | Экранированная управляющая последовательность |
| `\s` | Один пробел | Допустимо в строках и текстовых блоках Java 21 |
| `\"` | Двойная кавычка внутри строки | `"Нажми \"Войти\""` |
| `\'` | Одинарная кавычка, например внутри char-литерала | `char quote = '\'';` |
| `\\` | Одна обратная косая черта | `"C:\\Users\\servi"` |
| `\u0041` | Unicode escape, обрабатывается ещё до разбора кода | Обозначает `A`; это не только механизм строк |

Есть также восьмеричные escape-последовательности и продолжение строки через обратную косую черту с переводом строки в текстовом блоке; в первых тестах они обычно не нужны.
`"\\n"` — текст из обратной косой черты и буквы `n`, а `"\n"` — перевод строки.

## 7. Частые классы и методы Java

**Это библиотечные имена, не ключевые слова.** `java.lang` (включая `String`, `System`, `Math`) импортируется автоматически, другие пакеты обычно требуют импортов.

| Обозначение | Значение | Пример |
|---|---|---|
| `System.out.println(...)` | Напечатать значение и перевод строки | `System.out.println("Начало теста");` |
| `String.equals(...)` | Сравнить текст с учётом регистра | `"Анна".equals(actualName)` |
| `equalsIgnoreCase(...)` | Сравнить текст без учёта регистра | `"anna".equalsIgnoreCase(actualName)` |
| `contains(...)` | Проверить наличие подстроки | `message.contains("Успешно")` |
| `startsWith(...)`, `endsWith(...)` | Проверить начало/конец строки | `email.endsWith("@example.com")` |
| `length()` | Длина строки в кодовых единицах UTF-16 | `name.length()` |
| `isEmpty()` | Строка имеет длину ноль | `"".isEmpty()` |
| `isBlank()` | Строка пустая или состоит из пробельных символов | `"   ".isBlank()` |
| `strip()` | Удалить начальные и конечные пробельные символы | `" Анна ".strip()` |
| `trim()` | Удалить по краям символы с кодами не выше U+0020 | Для Unicode-пробелов поведение отличается от `strip` |
| `toLowerCase(...)`, `toUpperCase(...)` | Изменить регистр | `name.toLowerCase(Locale.ROOT)` — нужен `java.util.Locale` |
| `replace(...)` | Заменить буквальный фрагмент | `"+7 123".replace(" ", "")` |
| `replaceAll(...)` | Заменить совпадения регулярного выражения | `"a1b2".replaceAll("[0-9]", "")` |
| `split(...)` | Разделить строку по регулярному выражению | `"a,b".split(",")` |
| `substring(...)` | Взять часть строки, конечный индекс не включается | `"Анна".substring(0, 2)` даёт `"Ан"` |
| `String.format(...)` | Собрать строку по шаблону | `String.format("Имя: %s, возраст: %d", name, age)` |
| `Integer.parseInt(...)` | Преобразовать текст в `int` | `Integer.parseInt("25")` |
| `String.valueOf(...)` | Получить строковое представление | `String.valueOf(25)` |
| `Objects.equals(a, b)` | Сравнить объекты с учётом возможного `null` | `Objects.equals(expectedName, actualName)` |
| `List.of(...)` | Создать неизменяемый список | `List.of("Анна", "Иван")` |
| `new ArrayList<>()` | Создать изменяемый список | `List<String> names = new ArrayList<>();` |
| `add(...)`, `get(...)`, `size()` | Добавить, получить по индексу, узнать размер списка | `names.add("Анна");`, `names.get(0)`, `names.size()` |
| `Map.get(key)` | Получить значение по ключу | `user.get("name")`; может вернуть `null` |
| `Map.put(key, value)` | Записать пару в изменяемую карту | `user.put("name", "Анна")` |
| `Path.of(...)` | Создать представление пути | `Path.of("src", "test", "resources", "data.txt")` |
| `Files.readString(...)` | Прочитать файл в строку | `Files.readString(path)` — может потребовать `throws IOException` |
| `Duration.ofSeconds(...)` | Длительность | `Duration.ofSeconds(10)` |
| `LocalDate.now()` | Текущая дата по системным часам/часовому поясу | Для воспроизводимых тестов иногда лучше фиксированная дата |
| `Thread.sleep(...)` | Остановить поток на время в миллисекундах | В UI-тестах обычно заменять ожиданиями Selenide |

Строки Java неизменяемы: `name.strip()` не меняет `name`. Сохрани результат: `name = name.strip();`.
Индексы массивов, строк и списков начинаются с **0**. У массива длина — поле `names.length`, у строки — `name.length()`, у списка — `names.size()`.

## 8. JUnit: запуск и проверки

JUnit — библиотека для запуска тестов. Аннотации ниже относятся к JUnit Jupiter 5; проверки импортируются из `org.junit.jupiter.api.Assertions`.

| Обозначение | Значение | Пример / правило |
|---|---|---|
| `@Test` | Метод является тестом | `@Test void loginTest() { ... }` |
| `@DisplayName` | Понятное имя в отчёте | `@DisplayName("Поиск находит нужный результат")` |
| `@BeforeEach` | Подготовка перед каждым тестом | Открыть начальную страницу |
| `@AfterEach` | Завершение после каждого теста | Закрыть браузер |
| `@BeforeAll` | Подготовка один раз перед тестами класса | Обычно `static void setup()`, если не выбран жизненный цикл `PER_CLASS` |
| `@AfterAll` | Завершение после всех тестов класса | Обычно статический метод |
| `@Disabled` | Не запускать тест/класс | `@Disabled("Ожидаем исправление дефекта")`; пропуск не означает успех |
| `@Tag` | Метка для выбора группы тестов | `@Tag("smoke")` |
| `@Nested` | Группа тестов во вложенном нестатическом классе | Полезно для организации сценариев |
| `@ParameterizedTest` | Запустить один сценарий с разными данными | Требует источника данных |
| `@ValueSource` | Простой набор данных | `@ValueSource(strings = {"Анна", "Иван"})` |
| `@CsvSource` | Несколько параметров в каждой строке данных | `@CsvSource({"2, 3, 5", "1, 4, 5"})` |
| `@MethodSource` | Данные из метода | `@MethodSource("users")` |
| `@RepeatedTest` | Повторить тест заданное число раз | `@RepeatedTest(3)`; не замена исправлению нестабильного теста |
| `assertEquals(expected, actual)` | Значения равны | `assertEquals("Анна", actualName);` |
| `assertNotEquals(...)` | Значения не равны | `assertNotEquals("", actualName);` |
| `assertTrue(...)` | Условие истинно | `assertTrue(count > 0);` |
| `assertFalse(...)` | Условие ложно | `assertFalse(names.isEmpty());` |
| `assertNull(...)`, `assertNotNull(...)` | Значение `null` / не `null` | `assertNotNull(user);` |
| `assertSame(...)`, `assertNotSame(...)` | Ссылки на тот же объект / разные объекты | Это не сравнение содержимого |
| `assertArrayEquals(...)` | Поэлементное равенство массивов | `assertArrayEquals(expected, actual);` |
| `assertIterableEquals(...)` | Равенство элементов перебираемых объектов по порядку | Для списков |
| `assertThrows(...)` | Действие выбрасывает ожидаемый тип исключения или его наследника | `assertThrows(NumberFormatException.class, () -> Integer.parseInt("abc"));` |
| `assertDoesNotThrow(...)` | Действие не выбрасывает исключение | `assertDoesNotThrow(() -> Integer.parseInt("25"));` |
| `assertAll(...)` | Выполнить группу проверок и собрать их падения | `assertAll(() -> assertTrue(active), () -> assertEquals(25, age));` |
| `fail(...)` | Явно провалить тест | `fail("Неожиданный результат");` |

Обычный метод с `@Test` не должен быть `private` или `static`, обычно возвращает `void`. `public` для класса и метода JUnit 5 не обязателен.
JUnit-проверки выполняются сразу; они не ждут обновления страницы, в отличие от `shouldHave` и `shouldBe` Selenide.

## 9. Selenide: действия в браузере

Selenide — библиотека для взаимодействия с браузером поверх Selenium WebDriver.
Таблица описывает часто используемые методы, а не все возможности библиотеки.

### Найти и выполнить действие

| Обозначение | Значение | Пример |
|---|---|---|
| `open(url)` | Открыть страницу | `open("https://example.com");` |
| `$(selector)` | Описать один элемент по CSS-селектору | `$("#email")`; фактический поиск обычно откладывается до действия/проверки |
| `$$(selector)` | Описать коллекцию элементов | `$$(".result")` |
| `$(By.xpath(...))` | Найти через XPath | `$(By.xpath("//button[text()='Войти']"))`; импорт `org.openqa.selenium.By` |
| `element.$(...)` | Найти вложенный элемент внутри другого | `$("#form").$("button")` |
| `setValue(text)` | Заменить значение поля | `$("#email").setValue("test@example.com");` |
| `append(text)` | Дописать текст | `$("#name").append(" Иванов");` |
| `clear()` | Очистить поле | `$("#name").clear();` |
| `click()` | Нажать | `$("#submit").click();` |
| `doubleClick()` | Двойное нажатие | `$("#item").doubleClick();` |
| `contextClick()` | Нажатие правой кнопкой мыши | `$("#item").contextClick();` |
| `hover()` | Навести указатель | `$("#menu").hover();` |
| `pressEnter()` | Нажать Enter | `$("#search").pressEnter();` |
| `pressTab()` | Нажать Tab | `$("#email").pressTab();` |
| `setSelected(true)` | Установить checkbox в выбранное состояние | `$("#terms").setSelected(true);` |
| `selectOption(text)` | Выбрать пункт стандартного HTML `select` по тексту | `$("#country").selectOption("Россия");` |
| `selectOptionByValue(value)` | Выбрать по атрибуту `value` | `$("#country").selectOptionByValue("ru");` |
| `uploadFile(file)` | Загрузить файл через поле выбора файла | `$("input[type='file']").uploadFile(new File("document.txt"));` |
| `getText()` | Получить текст элемента | `String actual = $("#result").getText();` — не заменяет ожидание текста |
| `getValue()` | Получить значение поля | `String actual = $("#name").getValue();` |
| `getAttribute(name)` | Получить атрибут | `$("a").getAttribute("href")`; может вернуть `null` |
| `exists()`, `isDisplayed()` | Узнать существование/видимость в данный момент | Не замена ожидающим проверкам `shouldBe` |
| `refresh()`, `back()`, `forward()` | Обновить страницу, назад, вперёд | Статические методы `Selenide` |
| `closeWebDriver()` | Закрыть браузер и завершить его WebDriver | Обычно в `@AfterEach` |

### Проверки и ожидания

Для одиночных элементов условия обычно импортируются из `com.codeborne.selenide.Condition`, для коллекций — из `CollectionCondition`.

| Обозначение | Значение | Пример |
|---|---|---|
| `shouldBe(condition)` | Дождаться выполнения условия состояния и проверить его | `$("#submit").shouldBe(enabled);` |
| `shouldHave(condition)` | Дождаться свойства/содержимого | `$("#result").shouldHave(text("Успешно"));` |
| `shouldNotBe(condition)` | Дождаться отрицания условия состояния | `$("#loading").shouldNotBe(visible);` |
| `shouldNotHave(condition)` | Дождаться отсутствия свойства/содержимого | `$("#result").shouldNotHave(text("Ошибка"));` |
| `visible` | Элемент виден | `$("#form").shouldBe(visible);` |
| `hidden` | Элемент скрыт или отсутствует | `$("#loading").shouldBe(hidden);` |
| `exist` | Элемент существует в структуре страницы, не обязательно виден | `$("#form").should(exist);` |
| `enabled`, `disabled` | Элемент доступен / недоступен по соответствующему условию | `$("#submit").shouldBe(enabled);` |
| `checked` | Checkbox/radio отмечен | `$("#terms").shouldBe(checked);` |
| `text(value)` | Элемент содержит текст | `shouldHave(text("Готово"))` — не равенство всей строки |
| `exactText(value)` | Весь текст соответствует ожидаемому | `shouldHave(exactText("Готово"))` |
| `value(value)` | Проверка значения поля | `$("#email").shouldHave(value("test@example.com"));` |
| `attribute(name, value)` | Проверка атрибута | `$("a").shouldHave(attribute("href", "/login"));` |
| `cssClass(value)` | Проверка CSS-класса | `$("#notice").shouldHave(cssClass("success"));` |
| `size(number)` | Количество элементов коллекции | `$$(".result").shouldHave(size(3));` |
| `sizeGreaterThan(number)` | Количество больше указанного | `$$(".result").shouldHave(sizeGreaterThan(0));` |
| `texts(...)` | Проверка текстов элементов коллекции по порядку | `$$(".name").shouldHave(texts("Анна", "Иван"));` |
| `first()`, `last()`, `get(index)` | Выбрать элемент коллекции | `$$(".result").get(0)` |
| `findBy(condition)` | Найти первый элемент коллекции, подходящий под условие | `$$(".result").findBy(text("Анна"))` |
| `filterBy(condition)` | Отфильтровать коллекцию | `$$(".result").filterBy(visible)` |
| `Duration.ofSeconds(10)` | Явное время ожидания конкретной проверки | `$("#result").shouldBe(visible, Duration.ofSeconds(10));` |

Проверки текста Selenide имеют собственные правила регистра и пробелов; `text`/`exactText` обычно нечувствительны к регистру. Для регистрозависимых сравнений существуют `textCaseSensitive` и `exactTextCaseSensitive`. Уточняй семантику условия, если тест проверяет регистр или пробелы.

Selenide повторяет ожидающую проверку до успеха или истечения таймаута. Не добавляй `Thread.sleep` перед каждым действием.
Вызов `shouldHave` **не печатает автоматически подробный пошаговый отчёт** обо всём тесте.

### Настройки

| Обозначение | Значение | Пример |
|---|---|---|
| `Configuration.browser` | Браузер | `Configuration.browser = "chrome";` |
| `Configuration.browserSize` | Размер окна | `Configuration.browserSize = "1440x900";` |
| `Configuration.baseUrl` | Базовый адрес для относительных путей | При базе `"https://example.com"` вызов `open("/login")` откроет страницу входа |
| `Configuration.timeout` | Общее стандартное время ожидания Selenide в миллисекундах | `Configuration.timeout = 10000;` |
| `Configuration.headless` | Работа без видимого окна | `Configuration.headless = true;` |

Нужен импорт `com.codeborne.selenide.Configuration`. Глобальные настройки не меняй одновременно из параллельно выполняющихся тестов.

## 10. Селекторы: как найти элемент

Селектор — правило поиска элемента на странице. Строка внутри `$` интерпретируется как CSS-селектор, если не передан другой способ поиска.

| Обозначение | Значение | Пример в тесте |
|---|---|---|
| `#name` | Элемент с `id="name"` | `$("#name")` |
| `.result` | Элемент с CSS-классом `result` | `$(".result")` |
| `button` | По имени HTML-тега | `$("button")` — может быть много совпадений |
| `[name='email']` | Атрибут `name` равен `email` | `$("[name='email']")` |
| `[data-testid='submit']` | По специальному атрибуту для тестов | `$("[data-testid='submit']")` |
| `[aria-label='Search GitHub']` | По атрибуту доступности | Используется в текущем `SearchTests` |
| `[disabled]` | Атрибут присутствует | `$("button[disabled]")` |
| `[href*='login']` | Значение содержит подстроку | `$("a[href*='login']")` |
| `[href^='/user']` | Значение начинается с | `$("a[href^='/user']")` |
| `[href$='.pdf']` | Значение заканчивается на | `$("a[href$='.pdf']")` |
| `input[type='email']` | Тег и атрибут вместе | Поле электронной почты |
| `button.primary` | Тег и класс вместе | Кнопка класса `primary` |
| `#form input` | Любой потомок `input` внутри `#form` | Пробел — поиск на любой глубине |
| `#form > input` | Непосредственный дочерний элемент | `>` — только один уровень вложенности |
| `input + label` | Следующий соседний элемент `label` | Сразу после `input` с тем же родителем |
| `input ~ label` | Последующие соседние `label` | С тем же родителем |
| `button, a` | Объединение вариантов | Все кнопки и ссылки |
| `:checked` | Отмеченный элемент | `$("input:checked")` |
| `:nth-child(2)` | Второй дочерний элемент | Индексация здесь с 1, в отличие от Java-списков |
| `By.xpath(...)` | Поиск через язык XPath | `$(By.xpath("//button[text()='Войти']"))` |
| `byText(...)` | Selenide-поиск по тексту | `$(byText("Войти"))`; импорт из `com.codeborne.selenide.Selectors` |

В примере `$("[name='email']")` двойные кавычки ограничивают строку Java, а одинарные относятся к синтаксису селектора внутри этой строки.

Как проверить селектор:
1. Открой нужную страницу в браузере.
2. Нажми **F12 → Elements** или **ПКМ по элементу → Inspect / Просмотреть код**.
3. Найди `id`, `name`, `data-testid` или другой устойчивый атрибут.
4. В панели Elements нажми **Ctrl+F** и вставь селектор. Проверь, сколько элементов найдено.
5. По возможности выбирай уникальный устойчивый селектор, а не длинную цепочку и не случайно сгенерированный класс.

`id`, `name`, `value`, `class`, `type`, `href`, `placeholder`, `data-testid`, `aria-label` в HTML — имена атрибутов, а не ключевые слова Java. `class` в HTML и `class` в Java относятся к разным языкам.

## 11. Рабочий пример с разбором

Этот пример не требует сайта, браузера, регистрации или новых зависимостей.
Создай **отдельный** файл `src/test/java/learning/JavaBasicsTest.java` и вставь код целиком:

```java
package learning; // Пакет совпадает с папкой learning внутри src/test/java.

import org.junit.jupiter.api.DisplayName; // Подключаем аннотацию названия.
import org.junit.jupiter.api.Test;        // Подключаем аннотацию теста.

import static org.junit.jupiter.api.Assertions.assertEquals; // Подключаем проверку.

public class JavaBasicsTest { // Начало одного класса, как имя файла без .java.

    @Test // Этот метод запустит JUnit.
    @DisplayName("Удаление пробелов по краям имени")
    void removesSpacesAroundName() { // Имя метода и начало тела теста.
        // 1. Подготовка: задаём входные данные.
        String originalName = "  Анна  ";

        // 2. Действие: получаем результат операции.
        String actualName = originalName.strip();

        // 3. Проверка: ожидаемое значение слева, фактическое справа.
        assertEquals("Анна", actualName);
    } // Конец метода.
} // Конец класса.
```

Запуск: зелёный треугольник слева от метода → **Run**. Или из корня проекта:

```powershell
mvn -Dtest=learning.JavaBasicsTest test
```

Эта команда работает **после создания файла**, сам справочник не создаёт Java-класс автоматически.

### Разбор существующего браузерного теста

```java
open("https://github.com/search"); // Открыть страницу.

$("[aria-label='Search GitHub']") // Найти поле по атрибуту.
        .setValue("qa.guru")     // Вписать поисковый запрос.
        .pressEnter();          // Подтвердить ввод.

$("[data-testid='results-list']") // Найти область результатов.
        .shouldHave(text("QA.GURU")); // Дождаться ожидаемого текста.
```

Это фрагмент тела метода: полная версия с импортами и классом уже находится в `src/test/java/SearchTests.java`.
Перенос строки перед точкой не завершает инструкцию. Цепочка заканчивается `;`.
Доступность сайта, его разметка и данные могут меняться: синтаксически правильный тест не гарантирует вечного прохождения.

## 12. Как написать свой тест

1. **Назови проверяемое поведение.** Например: «При правильном запросе появляется нужный результат».
2. **Определи данные и ожидаемый результат.** Не пиши проверку после того, как просто посмотрел текущий ответ, не сверив требование.
3. **Создай класс в `src/test/java`.** Для пакета `learning` создай пакет через **New → Package → learning**, затем класс через **New → Java Class**.
4. **Укажи package и импорты.** Если IDEA создала пустой класс, не вставляй в него второй полный класс.
5. **Создай метод с `@Test`.** Метод `main` для JUnit не нужен.
6. **Подготовь начальное состояние.** Открой страницу, заполни необходимые данные.
7. **Выполни действие.** Например, нажми кнопку поиска.
8. **Добавь проверку результата.** Используй ожидающую проверку Selenide для обновляемой страницы.
9. **Запусти и прочитай результат.** Зелёный тест означает только выполнение записанных проверок.
10. **Проверь саму проверку.** В учебном примере временно укажи заведомо неверное ожидаемое значение, убедись, что тест падает, затем верни правильное.

Не включай в репозиторий настоящие пароли, токены, приватные SSH-ключи и рабочие пользовательские данные.
Тесты должны быть независимыми: один тест не должен требовать предварительного запуска другого.

### Частые действия в IDEA и Maven

| Обозначение | Значение |
|---|---|
| `main` + Tab | Шаблон точки входа обычной программы; в JUnit-тесте не нужен |
| `sout` + Tab | Сокращение редактора для `System.out.println(...)`; не слово Java |
| Alt+Enter | Предложенные исправления, например добавить импорт |
| Ctrl+Alt+L | Форматирование кода в стандартной Windows-раскладке IDEA |
| Reload All Maven Projects | Перезагрузить зависимости после изменения `pom.xml` |
| `mvn test` | Запустить тесты проекта, включая браузерный `SearchTests` |
| `mvn -Dtest=SearchTests test` | Запустить только указанный класс |
| `mvn -DskipTests test` | Скомпилировать тесты, но не запускать; это не доказательство их прохождения |
| `mvn -Dtest=LoggingConfigurationTest test` | Проверить текущую настройку логгера без браузера |

## 13. Ошибки и сокращения

### Сообщения

| Сообщение | Значение | Что проверить |
|---|---|---|
| `Cannot resolve symbol` | IDEA не может найти имя | Опечатки, импорт, Maven-зависимости, папку исходников |
| `';' expected` | Ожидалась точка с запятой | Конец текущей или предыдущей инструкции |
| `illegal start of ...` | Конструкция стоит в недопустимом месте | Скобки, импорт внутри класса, метод внутри метода |
| `class ... is public, should be declared in a file named ...` | Имя файла не совпало с публичным классом | Название `.java` |
| `NullPointerException` | Операция требует объект, но получен `null` | Где должна была появиться ссылка |
| `IndexOutOfBoundsException` | Индекс за пределами допустимого диапазона | Размер коллекции и индексацию с нуля |
| `AssertionFailedError` | Проверка JUnit не выполнена | Ожидаемое и фактическое значения |
| `Element not found` | Selenide не нашёл элемент за время ожидания | Адрес, селектор, iframe, вкладку и состояние страницы |
| `Element should have ...` | Элемент не удовлетворил ожидаемому условию | Текст, значение и соответствие требованию |
| `No SLF4J providers were found` | Не подключён исполнитель SLF4J-логирования | У нас уже настроен `slf4j-simple`; обнови Maven в IDEA |
| `Unable to find CDP implementation` | Нет подходящего модуля протокола DevTools браузера | Это предупреждение; отдельно смотри результат теста |
| `BUILD SUCCESS` | Maven успешно выполнил выбранные цели | Если тесты пропущены, это не означает «тесты прошли» |
| `1 test passed` | Один тест прошёл | Проверь, тот ли сценарий запускался |
| `exit code 0` | Процесс завершился успешно | Сам по себе не доказывает, что нужный тест запускался |

### Термины и сокращения

| Обозначение | Расшифровка | Простое объяснение |
|---|---|---|
| JDK | Java Development Kit | Набор для разработки: компилятор, среда выполнения и инструменты |
| JVM | Java Virtual Machine | Виртуальная машина, выполняющая Java-байткод |
| JRE | Java Runtime Environment | Среда выполнения Java; JDK уже содержит необходимое для запуска |
| IDE | Integrated Development Environment | Среда разработки, например IntelliJ IDEA |
| UI | User Interface | Интерфейс, с которым взаимодействует пользователь |
| API | Application Programming Interface | Интерфейс взаимодействия программ; браузерный и API-тест — разные способы проверки |
| HTML | HyperText Markup Language | Разметка элементов веб-страницы |
| CSS | Cascading Style Sheets | Язык оформления; его синтаксис селекторов используется для поиска элементов |
| DOM | Document Object Model | Представление структуры страницы в виде объектов |
| URL | Uniform Resource Locator | Адрес ресурса, например `https://example.com/login` |
| HTTP | Hypertext Transfer Protocol | Протокол запросов и ответов между клиентом и сервером |
| HTTPS | HTTP с защитой TLS | Шифрованное соединение с проверкой сертификата |
| JSON | JavaScript Object Notation | Текстовый формат данных, не Java-код |
| XML | Extensible Markup Language | Формат разметки; в нём написан `pom.xml` |
| XPath | XML Path Language | Язык выражений для поиска узлов, применяемый и к HTML-страницам |
| CDP | Chrome DevTools Protocol | Протокол дополнительных инструментов Chromium-браузеров |
| SLF4J | Simple Logging Facade for Java | Общий интерфейс логирования; `slf4j-simple` — одна из реализаций |
| POM | Project Object Model | Модель проекта Maven, описанная в `pom.xml` |
| AAA | Arrange, Act, Assert | Подготовка → действие → проверка |
| ООП | Объектно-ориентированное программирование | Организация программы через объекты и их взаимодействие |
| Page Object | Шаблон организации UI-тестов | Действия страницы выносят в отдельный класс; не ключевое слово Java |
